# ordem-paranormal-arquivos-secretos
Jogo de dedução lógica (estilo 'Cara a Cara') baseado no universo de Ordem Paranormal RPG, criado por 'Cellbit'. Desenvolvido em Java como projeto final da disciplina de Programação Orientada a Objetos (BCC), aplicando padrões de projeto (Facade), encapsulamento estrito e persistência de dados.
